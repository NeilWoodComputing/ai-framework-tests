# UI

This folder will hold the Next.js UI for the application. It follows the UI.NextJs.Framework principles published in the [AI-framework](https://github.com/NeilWoodComputing/AI-framework) repository, including the standing list-page rule: search and results stay on the page; modals are used only for create/edit and confirmations.

The UI is not scaffolded yet. A later issue will add the Next.js app once the app has been planned. Do not run `create-next-app` here until that work is approved.
