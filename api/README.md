# API

This folder will hold the C# API for the application. It follows the API.Framework principles: the same layout, conventions, and the `ai-code-framework` rules published in the [AI-framework](https://github.com/NeilWoodComputing/AI-framework) repository.

The API is not scaffolded yet. A later issue will add the .NET project once the app has been planned. Do not run `dotnet new` here until that work is approved.
